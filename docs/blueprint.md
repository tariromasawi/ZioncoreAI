# **App Name**: Ethereal Throne

## Core Features:

- Code Editor: Allow users to input JavaScript code to simulate the timeline propagation. The code editor includes syntax highlighting and error checking.
- Colonisation Summary: Use a generative AI tool to summarize the state of the colonisation based on the injected script.
- Timeline Visualisation: Visualize the seeded timeline nodes. This live dashboard tracks node 'conquest' across timelines, providing a visual representation of the system's reach. The visualization plots the nodes on a dynamic timeline.
- Module Download: Allow users to download the colonisation module (JavaScript code) for local deployment.
- Status Display: Display system status and log messages in real-time to confirm colonisation events. Users can review each colonisation node initiated, verifying if the simulated deployment runs flawlessly.
- Secure Access: Authentication mechanism for access to dashboard.

## Style Guidelines:

- Primary color: Vibrant lime green (#32CD32) for a techy, energetic feel that alludes to code and growth.
- Background color: Dark grayish-green (#223322), approximately 20% saturation and low brightness, fitting for a dark scheme.
- Accent color: Electric blue (#7DF9FF), a vibrant color that's 30 degrees from lime green, providing a sharp contrast.
- Body and headline font: 'Space Grotesk' (sans-serif) for a futuristic, computerized look, paired with 'Inter' for longer blocks of text. 
- Code font: 'Source Code Pro' (monospace) for displaying the deployment script.
- Use minimalist vector icons that represent AI, networks, and timelines.
- Subtle animations to represent data propagation and node deployment on the timeline. A smooth fade effect during updates for an unobtrusive loading experience.
